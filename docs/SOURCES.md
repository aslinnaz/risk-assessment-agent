# Sources: manifest, provenance and redistribution status

This file separates three different questions for every document:

1. **Is it used by the application?** (`catalogs/sources.json`, `rag`: true)
2. **May its text be sent to an external API?** (`api_transfer_allowed` in the manifest: an owner assertion, not verified here)
3. **May the file be redistributed in a public repository?** (assessed below; **public availability is not permission**)

Findings below come from the file metadata, the text of each PDF and the repository. Nothing was checked online, and no legal review was performed. Where permission is "not established", that means no licence or permission statement was found for the file itself, not that redistribution is forbidden.

## External-API transfer

Source passages are embedded through the OpenAI embeddings API on first start, and retrieved passages are included in prompts and in the report-time support check. The manifest field `api_transfer_allowed: true` records that the project owner permits this. It is an assertion, not a verified licence term. If a document's owner has not agreed to external processing, set it to `false` and `rag` to `false` (the document then stops being used) or obtain permission first.

## Setup process if a document is excluded from the public repository

1. Remove the file from the repository index (`git rm --cached sources/<file>`) and keep it in `.gitignore`.
2. Tell each new installer to obtain it from the rights holder (TrustAI documents) or from NIST (AI RMF Playbook) and copy it into `sources/` **with exactly the file name above**.
3. Verify with `python -c "import rag; rag.check_sources()"` and `python tools/verify_catalog.py` (expects 0 problems).
4. If the replacement file differs from the one in the table (different SHA-256), run `python tools/verify_catalog.py`: curated anchors (page and section references in `catalogs/*.json`) may need updating.
5. Tests that need the source PDFs skip when they are absent (86 offline tests still run). Do not treat a skip as a pass.

Removing a file from the index does **not** remove it from existing Git history; purging history is a separate decision (see HANDOVER).

## Sources added after deployment

`python tools/add_source.py add …` registers further documents under `sources/custom/` (git-ignored, local deployment data). Registration requires complete metadata, extractable text, no duplicate content and an explicit confirmation that indexing is permitted (`--indexing-permitted`). Copyrighted standards must not be added. See [DEVELOPER_GUIDE.md](DEVELOPER_GUIDE.md).
